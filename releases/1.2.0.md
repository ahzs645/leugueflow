# LeagueFlow 1.2.0

## Results workflow

- New **LeagueFlow → Results** screen for played games, grouped as Needs a score,
  Saved (not published), Scheduled to publish, Needs review and Published (last
  30 days), with a count on the menu. Each game takes a score or forfeit and is
  then published now, saved without publishing, or scheduled for a set time.
  Saved results can be published together.
- Publishing finishes the match, so it shows on the site and counts in the
  standings; an unpublished fixture is published with it. Holding a published
  result takes it back off the site.
- Scheduled results publish through WP-Cron (a single event plus a 15-minute
  sweep) as the person who scheduled them. A score changed after scheduling, or
  a match that can no longer be finished, stops for review instead.
- One `Result_Service` writes every result under the result lock in one
  transaction and records who saved what. The bulk Finished action shares its
  match checks.
- Scores that are not published are hidden from public lists, calendars, match
  pages and brackets. Live scores remain public unless held.
- The standings table no longer shows "Teams are listed; results will appear…".
- `wp leagueflow results finish-scored [--dry-run]` publishes scored or forfeited
  matches that were never finished. Postponed, cancelled, future and inconsistent
  matches are skipped.

## Calendar and layout

- CampusManager-style layout with the site's own brand: a scoped design-token
  layer (`assets/css/design-tokens.css`) that themes set on `.leagueflow`, pill
  tabs, card shells, accent-pill event cards, list groups with count pills.
- Phone month view: a compact day grid with event dots and the selected day's
  games under it; details open as a bottom sheet. Touch targets are at least 44px.
- Standings tables, team cards and match rows use the same cards and tokens.
- Tapping a month day keeps focus on that day.

Installing this update does not change existing results. Pair it with the
Intramurals theme release that sets the new tokens; older theme overrides are
removed there.
