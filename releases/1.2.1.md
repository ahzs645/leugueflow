# LeagueFlow 1.2.1

LeagueFlow 1.2.0 was not published as a separate GitHub release, so this update
also delivers everything in the [1.2.0 release notes](https://github.com/ahzs645/leugueflow/blob/v1.2.1/releases/1.2.0.md): the
**LeagueFlow → Results** screen (publish, hold or schedule results), the
CampusManager-style calendar and card layout with theme design tokens, one match
card everywhere, continuous standings rows, and classic-editor calendar events
with poster images.

## Standalone Drop-in activities

- The **Calendar Event Details → Sport / activity** menu now includes **Drop-in (all sports)** alongside enabled sports.
- Selecting Drop-in saves an unscoped calendar event rather than creating a fake sport. It automatically sets the event type to **Drop-in** and clears its previous sport, competition and season assignments.
- Standalone drop-ins appear in the all-sports calendar and in calendars filtered by **event type: Drop-in**. Sport-specific calendars continue to contain only activities belonging to that sport.
- Switching an event back to Soccer, Basketball, Volleyball, or another enabled sport is supported when its competition and season selections are valid.
- Existing sport-specific events and their fields are unchanged unless an editor explicitly selects the standalone Drop-in choice.
- Regression tests cover the dropdown, conversion from and back to a sport, and calendar visibility.

## Referee desk

- Referees, alone or alongside a player role, open the front-end **Referee desk**
  from the account menu. They can search every published game and team and see both
  rosters.
- A referee can publish a score or save it for staff review through the same result
  writer as the Results screen. Assigning a referee to a game is optional.
- A referee who plays in a game is flagged and can only save that game's score for
  staff, not publish it.

## Updates and compatibility

- The plugin continues to update from `ahzs645/leugueflow` via verified GitHub release assets.
- Requires WordPress 6.5+ and PHP 8.1+. The package retains the `leagueflow/` plugin directory. Updating plugin files does not intentionally remove league data.
- Back up the production site and test the calendar and any theme-specific overrides on staging before updating a live intramurals site.
